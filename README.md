# 🏰 Luxury Resort & Hotel Management Dashboard

A modern, responsive, and elegant web-based Resort & Hotel Management Dashboard built with HTML5, CSS3, and JavaScript (ES6+). Designed with a luxury dark theme featuring gold accents, dynamic room/service cards, booking logic, and full mobile responsiveness.

---

## ✨ Features

- 🏨 **Resort Hero Banner**: Custom luxury hero layout with overlay lighting and quick stats.
- 🔐 **Admin Login Modal**: Animated login modal overlay with backdrop blur.
- 📊 **Interactive Dashboard**: Real-time stat cards tracking bookings, total revenue, available rooms, and guests.
- 🛌 **Room & Service Management**: Dynamic rendering of room cards and resort amenities.
- 📝 **Reservation & Billing System**: Interactive guest booking form with automated invoice calculation.
- 📱 **Mobile First Design**: Fully responsive layout with custom mobile drawer navigation and bottom bar.
- 🎨 **Luxury Dark Theme**: Premium UI crafted with CSS variables, keyframe animations, and glowing status indicators.

---

## 🛠️ Tech Stack

- **HTML5**: Semantic HTML markup.
- **CSS3**: Custom CSS variables, Flexbox, CSS Grid, media queries, and dynamic animations.
- **JavaScript (ES6+)**: DOM manipulation and modal/tab navigation management.
- **Typography & Icons**: Google Fonts (`Poppins`, `Playfair Display`) and FontAwesome icons.
